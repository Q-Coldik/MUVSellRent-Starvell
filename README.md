# MUVSell Rent (Starvell) — плагин Starvell Cardinal

Перепродажа аренды и оффлайн-активаций Steam-аккаунтов с [muvsell.store](https://muvsell.store) на Starvell — без своих аккаунтов.

Покупатель оплачивает ваш лот на Starvell → плагин арендует аккаунт на MUVSell через API (списывает ваш баланс MUVSell по цене сайта) и присылает логин и пароль в чат заказа. Разница цен — ваш заработок, наценку задаёте сами.

Плагин бесплатный, код открыт — это один файл [`MUVSellRentStarvell.py`](MUVSellRentStarvell.py).

Плагин для FunPay Cardinal — в репозитории [MUVSellRent](https://github.com/Q-Coldik/MUVSellRent), модуль для Playerok — в [MUVSellRent-Playerok](https://github.com/Q-Coldik/MUVSellRent-Playerok).

## Что умеет

### Аренда

- Один лот на игру в Steam → «Аккаунты с играми» → «Аренда», **1 шт = 1 час**: покупатель берёт 5 шт — получает аккаунт на 5 часов
- **Автовыдача** логина и пароля сразу после оплаты
- **Коды Steam Guard** по команде `!код`; `!время` — сколько осталось, `!данные` — логин и пароль ещё раз, `!помощь` — список команд
- **Продления** командой `!продление` — время добавляется к тому же аккаунту
- **Команды `!кик` и `!пароль`** для покупателя (включаются в настройках)
- Лот аренды **выключается, пока на MUVSell нет свободных аккаунтов**, и включается сам

### Оффлайн-активации «игра навсегда»

- Лот на игру в «Аккаунты с играми» → «Продажа»: 1 шт = игра навсегда на общем аккаунте MUVSell, до 10 за заказ
- После оплаты покупатель получает логин, пароль и инструкцию; код Steam Guard — тем же `!код`, данные ещё раз — `!офлайн`

### Лоты и учёт

- **Автовыставление** с картинкой игры; новые игры MUVSell выставляются сами; дубли удаляются
- **Пересчёт цен** с наценкой
- **Бонус за отзыв** — дополнительные часы аренды за хорошую оценку (по желанию)
- **Возвраты:** возврат на Starvell завершает аренду этого заказа; если выдача не удалась — автовозврат
- Статистика продаж и прибыли
- **Английский:** на английские команды (`!code`, `!time`…) плагин отвечает по-английски

## Установка

1. Нужен [Starvell Cardinal](https://github.com/etheriumflipper/Starvell-Cardinal) (проверено на 0.3.25).
2. Скачайте [`MUVSellRentStarvell.py`](MUVSellRentStarvell.py) и положите в папку `plugins/` (или загрузите через «🧩 Плагины» в Telegram-боте), перезапустите бота.
3. Зарегистрируйтесь на [muvsell.store](https://muvsell.store), пополните баланс и создайте API-ключ: **Профиль → API**.
4. В Telegram-боте напишите `/muvsell` — вставьте API-ключ, задайте наценку и выставьте лоты.

Новые версии плагин ставит сам; их также можно скачать в профиле на [muvsell.store](https://muvsell.store).
